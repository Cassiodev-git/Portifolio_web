CashFlow

CashFlow é uma aplicação full-stack de controle financeiro pessoal, criada para registrar receitas e despesas, organizar transações por categorias e acompanhar o saldo atual do usuário. O projeto possui autenticação com JWT, dashboard com resumo financeiro, gráfico de entradas e saídas, busca de transações, gerenciamento de categorias e integração entre frontend React e backend Node.js com MySQL.
